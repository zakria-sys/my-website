# ملفات الألعاب التي يسمح بإعادة توزيعها

هذا المجلد مخصص فقط لملفات التثبيت التي نملكها أو التي يسمح ترخيصها صراحةً بإعادة توزيعها.

قبل إضافة أي ملف:
1. تحقق من ترخيص اللعبة وشروط إعادة التوزيع.
2. احتفظ باسم اللعبة والإصدار ونظام التشغيل ورابط المصدر والترخيص.
3. افحص الملف بمضاد فيروسات، ولا ترفع ملفات مجهولة أو معدلة.
4. لا ترفع ألعاباً تجارية مدفوعة أو ملفات APK من مصادر غير موثوقة.

لا توجد حالياً ملفات ألعاب مستضافة في هذا المجلد. استخدم روابط المطورين الرسمية الموجودة في الموقع إلى أن نضيف ملفات مرخصة بشكل صحيح.
